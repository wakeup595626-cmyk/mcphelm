# 新手上手教程（桌面版）

> 返回 [README](../README.md) ｜ 命令行用户请看 [快速开始](quickstart.md)

这份教程面向**完全没碰过命令行**的新用户：从双击图标开始，到让 ChatGPT 用上你电脑里的能力，全程只用鼠标。大约 10 分钟。

## 这个软件到底是干嘛的

你电脑上可能跑着一些「本地 AI 能力」——比如能读你文件的助手、能查你笔记的工具。它们技术上叫 **MCP 服务器**。

ChatGPT 本身碰不到你电脑里的这些东西（这是好事，安全）。OpenAI 官方提供了一条「安全隧道」，让你的电脑和 ChatGPT 之间搭一座桥，桥两头都验证身份，中间加密。

**MCPHelm 就是管这座桥的**：不用记命令、不用敲代码，点几下鼠标就能把桥搭好、看着它跑、出问题自动帮你修。

## 第一步：打开软件

双击桌面上的 **MCPHelm** 图标。第一次打开会看到一个「三步上手」的引导页，不用慌，跟着走就行。

> 窗口关掉后软件其实还在右下角托盘里继续跑（桥不会断），双击托盘图标就能再叫出来。想彻底退出：托盘图标右键 → 退出。

## 第二步：下载"发动机"（运行环境）

隧道要跑起来，需要一个 OpenAI 官方的小程序（叫 tunnel-client），MCPHelm 帮你自动下载。

点引导页第 ① 步的 **「一键下载」**，等进度走完。它会从 OpenAI 官方仓库下载，并自动做完整性校验，下错了会自己重试。

> 如果你的网络访问 GitHub 有困难，可以手动去官方仓库下 zip，然后在「设置 → 运行环境 → 导入本地安装包」里选它。

## 第三步：告诉它你要暴露什么（添加服务器）

点第 ② 步的 **「添加服务器」**，会弹出一个表单。这里分两种情况：

**情况 A：你用别人做好的 MCP 服务器**（最常见）
- 类型选「命令型 (stdio)」
- 启动命令类似 npx -y @modelcontextprotocol/server-everything 这样的一行
- 不确定填什么？点 **「从模板新建」** 挑一个常用的，一键填好

**情况 B：你自己已经在电脑上跑着一个服务**
- 类型选「HTTP 服务」
- 地址填类似 http://127.0.0.1:3001/mcp

> 已经在用 Claude Desktop / Cursor / VS Code？点 **「导入已有配置」**，它能自动把那边配好的服务器搬过来，不用重新填。

## 第四步：去 OpenAI 拿两把"钥匙"

这一步要离开软件，去 OpenAI 平台拿两样东西（引导页下方的说明卡有直达链接）：

| 要拿什么 | 去哪拿 | 长什么样 |
| --- | --- | --- |
| 隧道 ID | OpenAI 平台 → 隧道管理 | tunnel_ 开头 + 32 位字符 |
| 密钥（runtime key） | OpenAI 平台 → API 密钥 | sk- 开头的一长串 |

> 这两样东西相当于桥的门票和门锁，**只存在你自己电脑上**，MCPHelm 不会上传。

## 第五步：搭桥（创建并启动隧道）

回到软件，点第 ③ 步的 **「创建隧道」**：

1. 绑定服务器：选第三步加好的那个
2. 隧道 ID：粘贴第四步拿到的隧道 ID
3. 密钥来源：选 **「密钥保险箱（推荐）」**，把密钥粘进去一次——它只进 Windows 凭据管理器，不写进任何文件
4. 点「创建」，再点卡片上的 **「启动」**

启动后看到状态变成「运行中」，桥就搭好了。

## 第六步：在 ChatGPT 里用

打开 ChatGPT → 设置 → 连接器，把刚建的那条隧道加进去。之后你直接在对话里就能调用电脑里的那个能力了。

## 日常使用：你需要知道的三件事

**关掉窗口 ≠ 断线**。窗口关了桥还在，想彻底关就托盘右键退出。

**隧道掉线会自动拉起**。软件里有守护进程盯着，意外断开会自动重连，并在右下角弹通知告诉你。短时间内反复失败才会停下并在日志里给出原因。

**出问题先点「体检」**。左侧导航的「体检」会自动检查环境、配置、连通性，每一项问题都附带「怎么修」的建议，照着做就行。

## 常见疑问

**装到 C 盘会不会占空间？**
不会。软件自己产生的所有东西（配置、日志、下载缓存、临时文件）都放在「数据目录」里，默认跟着安装位置走——装到 D 盘，数据就全在 D 盘，C 盘零占用。想换地方：设置 → 数据位置 → 迁移到其他盘。

**密钥安全吗？**
选「密钥保险箱」时，密钥只进 Windows 凭据管理器（和系统存 Wi-Fi 密码一个地方），配置文件里一个字符都不留。

**卸载会删我的数据吗？**
不会。卸载只删程序本身，配置和日志保留在数据目录里，重装后原样恢复。

**命令行用户去哪了？**
这份教程是给鼠标党的。喜欢用命令行的话，同样的事情 CLI 都能做，见 [快速开始](quickstart.md)。
