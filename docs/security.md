# 安全说明

> 返回 [README](../README.zh.md)

## 一句话版本

**runtime key 只走环境变量，面板只听 127.0.0.1，运行时二进制强制校验官方哈希，不收集任何遥测。**

## 密钥是怎么走的

1. 配置里通常只写**环境变量的名字**（`apiKeyEnv`，默认 `CONTROL_PLANE_API_KEY`），key 本身不落盘；
2. `mcphelm start` 时从当前进程环境里读出值；
3. 只在 `spawn()` 官方 runtime 时，通过子进程环境变量传入；
4. 结束。

它**不会**出现在下面任何地方：

| 位置 | 是否会出现 key |
| --- | --- |
| 配置文件 | 只有变量名（除非你主动使用明文 `apiKey`） |
| 子进程命令行 | 不会（命令行会出现在进程列表里，所以刻意避开） |
| 日志文件 `~/.mcphelm/logs/*.log` | 不会 |
| 状态文件 `~/.mcphelm/run/*.json` | 不会（隧道 ID 也只存打码版） |
| `config show` / `status` / `doctor` / 面板 | 不会，统一打码为 `sk-*** (len 51)` 这种形式 |
| 子进程的环境变量 | **会** —— 这是唯一的传输通道，也是官方 runtime 期望的读法 |

## 明文 `apiKey` 的取舍

为了本地临时调试方便，配置里也允许直接写 `apiKey`。请把它当成"明放在桌面上的便利贴"：

- 只在你自己的机器、自己的用户目录下这么用；
- 别提交到 Git（本项目的 `.gitignore` 不会保护你的配置文件，因为它可能叫任意名字）；
- 用完就删，改回 `apiKeyEnv`；
- 即便这样，`config show` 与面板也都只会显示打码结果。

## 本地面板

- 默认只绑定 `127.0.0.1`，局域网其它机器访问不到；
- **没有鉴权**：任何能连上这个端口的本机程序都可以读状态、启停隧道。这是有意的取舍——面板定位是"我自己机器上的开关"，不是多用户服务；
- 所以：不要用 `--host 0.0.0.0` 开放到局域网，不要用 Nginx / frp 之类把它转发到公网。如果你确实需要远程访问，请自己在前面加一层带认证的反向代理，并明白那已经超出本工具的威胁模型；
- 面板的写操作只有 `start` / `stop` 两个，且有并发锁；`/api/*` 里的其余接口都是只读的。

## 运行时供应链

- 只从 openai/tunnel-client 的 **官方 GitHub Releases** 下载；
- 安装前强制比对官方 `SHA256SUMS.txt`：哈希对不上、或者 SUMS 里找不到对应文件，一律中止安装；
- `--skip-verify` 是逃生舱（例如你在离线环境里已经用别的方式核对过压缩包），用了它就意味着跳过了这一层保护，日志里会留下明确警告；
- 本项目不修改、不重新打包、不重新分发官方二进制。

## 项目会联网做什么

| 场景 | 目标 | 是否默认发生 |
| --- | --- | --- |
| `mcphelm runtime fetch` | GitHub API + Releases 下载压缩包与 SHA256SUMS | 只有你主动执行时 |
| `mcphelm doctor --online` | GitHub API 查询最新版本号 | 只有加了 `--online` 时 |
| `mcphelm status --health`、面板 | 本机 `127.0.0.1:<port>/healthz`、`/readyz` | 只探测本机端口 |
| `mcphelm doctor` 探测 HTTP 型 MCP | 你在配置里写的那个 URL | 只探测你配置的地址 |

没有任何遥测、统计上报、更新检查或第三方分析；不执行 `runtime fetch` 就完全不会访问外网。

## 本项目不保护什么

- **本机恶意软件**：能读你用户环境变量的程序，自然也能拿到 key。这是所有"把密钥放在环境变量里"的方案共同的前提；
- **被投毒的 MCP 服务器**：你接入的 MCP 服务器本身就是被授予能力的对象，它的行为由你负责审查；
- **多用户共享机器**：面板端口在本机 loopback 上对**所有本地用户**可见，共享机器上请另行隔离；
- **OpenAI 平台侧的策略与配额**：隧道权限、组织策略、计费等都在平台侧控制；
- **配置文件自身的权限**：`mcphelm.config.json` 与 `~/.mcphelm/` 的读写权限由操作系统管，你可以在 POSIX 上 `chmod 600`，在 Windows 上收紧 ACL。

## 自查清单

- [ ] key 放在环境变量里，配置中只出现 `apiKeyEnv`
- [ ] 不用 `--host 0.0.0.0`，也没有把面板端口映射到公网
- [ ] `mcphelm doctor` 全绿后再启动隧道
- [ ] 看到 `--skip-verify` 时知道自己在做什么
- [ ] 截图、贴日志前扫一眼有没有敏感信息（日志里本来不含密钥，但你的 MCP 服务器自己打印的内容不受此保证）
